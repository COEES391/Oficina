# **App Name**: AsistenciaFacil

## Core Features:

- Attendance Logging: Record attendance with date, time, course, and user RFC upon entry and exit.
- Data Filtering and Reporting: Filter data and generate attendance reports by date, course, or user RFC.
- User Authentication: Secure user login using RFC for verification.

## Style Guidelines:

- Primary color: Soft blue (#89BBE3), evoking trust and efficiency, ideal for professional use.
- Background color: Light gray (#F0F4F7), offering a clean and neutral backdrop to ensure readability.
- Accent color: Deep blue (#3F51B5) is used to draw attention to key actions and interactive elements. 
- Font: 'Inter', a sans-serif font, for clear readability and a modern interface in both headings and body text.
- Use simple, clear icons for navigation and status indication.
- Design a clean, intuitive layout for easy data input and report viewing.
- Use subtle animations for feedback on attendance logging.
